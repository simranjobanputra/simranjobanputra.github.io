Sight Machine · Enterprise · B2B2B

Role-based access for factory data

I designed role-based access for Sight Machine’s manufacturing platform as the only designer, in 8 weeks. It was one of the main reasons two Fortune 500 machine makers signed.

2Fortune 500 machine makers signed
8 weeksfrom research to production

The challenge

Sight Machine sells its analytics software bundled with machine makers’ equipment. Every factory a machine maker sold to got its own Sight Machine environment, so machine makers juggled a separate login for each customer.

Moving them into one shared environment meant solving access: each factory can only see its own data, while the machine maker needs to see across all of them.

Solution

One settings home where machine makers create a team for each customer, add users, and set exactly which plants and data each team can see.

Access control sits alongside the platform settings instead of being bolted onto the old menu, so admins manage everything in one place.

Process

01

Co-design with machine makers

Customer groups, access cards, flippable team cards and a pop-over for adding users. The sessions also showed where the flow between pages broke down.

02

One home for settings

Before: unrelated settings on one page and no user settings at all. After: a settings landing page that sends you to profile, users, teams, feature toggles and more.

03

Creating a team

Name the team in place, add members with contextual search, and see who’s selected before you apply.

The design

Teams, members, and permissions in one place.

Machine makers build teams for each customer, assign roles and permissions, and manage every group from a single environment.
